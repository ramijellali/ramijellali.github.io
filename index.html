TunTTS & the autonomous phone agent

Converty · Jun 2025 – Jan 2026
In production

Tunisian Arabic has no commercial text-to-speech support. So I built it. Fine-tuned Coqui XTTS-v2 through transfer learning into a natural-sounding Darija voice, chosen after benchmarking Google and OpenAI TTS (MSA-only) and VITS-from-scratch. Then shipped an autonomous phone agent: every new order triggers an outbound VoIP call where the agent reads the order back and collects spoken confirmation in dialect. In-call tools run as MCP servers. The full workflow completes with no human in the loop.

About
