TunTTS & the autonomous phone agent

Converty · Jun 2025 – Jan 2026
In production

Tunisian Arabic has no commercial text-to-speech support. So I built it. Fine-tuned Coqui XTTS-v2 through transfer learning into a natural-sounding Darija voice, chosen after benchmarking Google and OpenAI TTS (Modern Standard Arabic only) and VITS-from-scratch. Then shipped an autonomous phone agent on top: every new order triggers an outbound VoIP call where the agent reads the order back and collects spoken confirmation in dialect. In-call tools for modification, cancellation and refund run as MCP servers, so the same tools served both the gpt-realtime stack and the ADK/Gemini agents under benchmark. The full workflow completes with no human in the loop.

FarmWise — offline RAG for rural agronomy

ESPRIT · presented at Bal des Projets 2025 · I owned both AI cores
Team of 5

Farmers in low-connectivity zones can't call an API. So the assistant runs entirely offline: 13 agronomy books distilled into 2,549 FAISS chunks, served by a local Mistral model through Ollama — zero API cost, zero connectivity required. Live context is injected from four IoT sensor streams and two plant APIs, and a ResNet-50 classifier reads Sentinel-2 satellite tiles pulled on demand from Google Earth Engine.
